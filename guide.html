CONFIGURATION GUIDE

Follow these exact steps to get your LaLiga Portal fully working. Takes about 15 minutes.

1 Get Football Data API Key (FREE)
aGo to football-data.org/client/register
bFill in your name and email → click Register
cCheck your email inbox → copy the API key they send you
dOpen js/api.js in your GitHub repo → click the pencil (edit) icon
eFind line 4 and replace the placeholder with your key:
// BEFORE: const API_KEY = "PASTE_YOUR_FOOTBALL_DATA_API_KEY_HERE"; // AFTER (example): const API_KEY = "a1b2c3d4e5f6a1b2c3d4e5f6a1b2c3d4";
fScroll down → click Commit changes → Commit changes (green button)
ℹ️ The free plan gives you 10 API calls/minute. The site caches responses so this is plenty.
2 Create Firebase Project (FREE)
aGo to console.firebase.google.com → Sign in with Google
bClick "Add project" → Name it laliga-portal → Continue → Create project
cEnable Email/Password Auth: Left sidebar → Build → Authentication → Get started → Email/Password → Enable → Save
dCreate Firestore: Left sidebar → Build → Firestore Database → Create database → Start in test mode → Next → Choose any region → Enable
eSet Firestore Rules: Firestore → Rules tab → Replace ALL content with this:
rules_version = '2'; service cloud.firestore { match /databases/{database}/documents { match /users/{userId} { allow read: if request.auth != null; allow create: if request.auth != null && request.auth.uid == userId; allow update: if request.auth != null && ( request.auth.uid == userId || get(/databases/$(database)/documents/users/$(request.auth.uid)).data.role in ['admin', 'moderator'] ); } match /settings/{doc} { allow read: if true; allow write: if request.auth != null && get(/databases/$(database)/documents/users/$(request.auth.uid)).data.role in ['admin', 'moderator']; } } }
fClick Publish to save the rules
3 Get Firebase Config & Paste It
aIn Firebase Console → Click ⚙️ gear icon (top left) → Project settings
bScroll down to "Your apps" → Click the </> (Web) icon
cApp nickname: laliga-portal → click Register app
dYou'll see a config object like this — copy all the values:
// You will see something like this in Firebase: const firebaseConfig = { apiKey: "AIzaSyXXXXXXXXXXXXXXXXXXXXXXXXXXXX", authDomain: "laliga-portal.firebaseapp.com", projectId: "laliga-portal", storageBucket: "laliga-portal.appspot.com", messagingSenderId: "123456789012", appId: "1:123456789012:web:abcdef123456" };
eGo to your GitHub repo → open js/firebase-config.js → click ✏️ pencil to edit
fReplace every PASTE_YOUR_..._HERE with your real values
gClick Commit changes
⚠️ Do NOT add databaseURL — it's not needed and will cause errors.
4 Create the Admin Account
aWait ~2 minutes for GitHub Pages to redeploy after your edits
bVisit your site → go to pages/login.html
cScroll to the bottom of the login page → open "⚙️ First time / Admin setup"
dClick "Create Admin Account" → you should see a green success message
eNow log in with: sakibhasn85@gmail.com / Sakib1998!
5 Verify Everything Works
aVisit your site's setup.html page to run automated checks
bAll 4 checks should show ✅ green
cIf any fail, the checker shows you exactly what to fix
